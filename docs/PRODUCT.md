# Blockpons — Product brief

## 目的
ブロック配置とライン消去による短時間プレイ向けパズルを Web・Android・iPhone で提供する。

## MVP スコープ
- 8×8 盤面（仮：仕様 Issue で確定）
- 3つの候補から任意のピースを選び、ドラッグ操作で配置
- 配置可能セルのハイライトと、不正配置の防止
- 完成した行・列を同時に消去して得点を獲得
- 3候補を使い切ったら補充
- 配置できる候補がなければゲームオーバー
- 再挑戦、スコア、ローカルハイスコア、効果音 ON/OFF
- マウス・タッチ操作、端末の縦向きに対応

## 要確認（実装前に Issue で確定）
- 盤面サイズ、出現ピースの種類と生成確率
- 得点式・連続消去ボーナスの有無
- 出現ピースに必ず合法手を含めるかどうか
- 操作時の指のオフセット・キャンセル条件
- 色弱対応・演出速度・振動の扱い

## 非スコープ（MVP）
アカウント、クラウド同期、ランキング、広告、課金、サーバー、オンライン対戦。

## 品質目標
- ルール部分の決定的な単体テスト
- 盤面状態と画面表示の整合
- 端末サイズ差・タッチ/マウス差のテスト
- Web と Android の CI ビルド
- iOS は署名が可能な実機環境で確認し、CI 化を別タスクで判断

## 完了条件
Web、Android、iOS の各環境でゲーム開始→配置→消去→終了→再挑戦ができること。各環境の基本操作・表示・ハイスコア保存を確認すること。
