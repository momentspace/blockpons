# Blockpons

Web / Android / iOS 対応の、ブロック配置型パズルゲーム（オリジナル実装）。

> 現在は企画・Issue整理フェーズです。ゲーム本体は未実装です。

## 目標
- 3つのピース候補から盤面へドラッグ＆ドロップで配置
- 行・列をそろえると消去して得点獲得
- スマートフォンの縦画面を優先し、Web のマウス操作もサポート
- 3環境で共通のルールと操作感、オフラインプレイ

## 初期技術方針（ADRで確定予定）
- **Flutter / Dart**：Web、Android、iOS を単一リポジトリで管理
- 盤面・配置・消去・スコアは UI に依存しない pure Dart として実装
- ローカル端末へのハイスコア保存。認証・サーバーは初期MVPに含めない
- GitHub Actions で静的解析・単体テスト・Webビルド・Androidビルド
- iOS ビルドと配布には macOS / Xcode / Apple 側の署名設定が必要

## 想定構成
```text
lib/
  app/           # アプリ起動・画面遷移
  game/domain/   # ピース・盤面・ルール・スコア（Flutter非依存）
  game/ui/       # ゲーム画面・入力・演出
  storage/       # 設定とスコア保存
test/            # ドメイン中心の単体テスト
integration_test/
docs/adr/        # 技術上の意思決定
.github/ISSUE_TEMPLATE/
```
上記は実装予定のディレクトリで、現時点で存在するものではありません。

## 開発の進め方
1. [Issues](https://github.com/momentspace/blockpons/issues) の仕様確定・基盤整備
2. Web でゲームコアループを完成
3. Android と iOS のビルド・操作検証
4. 品質・アクセシビリティ・公開準備

Issue は `epic` / `type` / `platform` / `priority` の観点で整理します。

## 権利と独自性
他作品の名前・ロゴ・画像・音源・コードをコピーしません。ゲームジャンルや一般的な操作方法を参考にしつつ、UI・演出・アセットは独自制作します。商用公開前に名称・素材・ストア規約を改めて確認します。
